Features

Everything a screen recorder does, minus the re-takes

scriptreel drives a real Chromium browser with Playwright and composites every frame itself, so the result looks the same on any machine.

🖱️

Smooth cursor

Glides along natural eased curves, with click ripples. No jittery mouse.

🔍

Auto-zoom

The camera zooms into whatever is being clicked or typed into, then eases back out.

💬

Captions & subtitles

On-screen captions, plus an .srt file from per-step voice-over lines.

🪟

Browser frame

Light or dark window chrome, rounded corners, shadow and gradient backgrounds.

🙈

Privacy built in

Blur emails and API keys in every frame. Secrets come from env vars and never show in logs.

📐

Any format

MP4, WebM or GIF at YouTube, vertical reel, square, 720p or 4K sizes.

🎯

Deterministic

A virtual clock means the same script gives the same video on a laptop or a slow CI runner.

🤖

Runs in CI

Re-record every demo on each release with GitHub Actions. Your docs never go stale.

    Install
    
    
    Up and running in three commands
    
    
    You need Node.js 18.18 or newer. ffmpeg is bundled with the package. Chromium is installed once through Playwright.
    
    
    
      
    Create a script
    npx scriptreel init
    Writes an example demo.yml that you edit to match your app.
    
      
    Install Chromium (once)
    npx playwright install chromium
    On Linux CI, add --with-deps.
    
      
    Record
    npx scriptreel record demo.yml -o demo.mp4
    Add --format gif,webm for extra formats.

    Why scriptreel
    
    
    Demo videos that never go out of date
    
    
    
      
    ⏱️
    Stop re-recording
    When a button moves, change one line and re-run instead of re-shooting the whole video.
    
      
    🔁
    Reviewable like code
    Demos live in git, so changes go through pull requests like any other change.
